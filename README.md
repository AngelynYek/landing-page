# Landing Page Project

A responsive landing page built from scratch as part of [The Odin Project's Foundations Curriculum](https://www.theodinproject.com/lessons/foundations-landing-page).

The project focuses on implementing simple layout structures with CSS Flexbox, handling typography, and replicating a design mockup accurately.

---

## Features

- **Semantic HTML5:** Structured sections using `<nav>`, `<header>`, `<div>`, and `<footer>`.
- **Flexbox Architecture:** Utilizes CSS Flexbox for navigation, hero section alignments, grid-like card layouts and vertical centering.
- **Typography:** Custom font integration using [Roboto](https://fonts.google.com/specimen/Roboto) via Google Fonts.
- **Modern Reset:** Uses modern box-sizing (`border-box`) to ensure consistent element sizing across browsers.

---

## Technologies Used

- **HTML5**
- **CSS3** (Flexbox)
- **Git & GitHub** (Version Control & GitHub Pages)

---

## Sections Included

1. **Header / Navbar:** Logo with right-aligned navigation links.
2. **Hero Section:** High-contrast introduction with heading, supporting text, call-to-action button, and image block.
3. **Information Section:** Centered section showcasing 4 visual cards with subtext.
4. **Testimonial / Quote:** Light-contrast block quote with a right-aligned author attribution.
5. **Call to Action (CTA):** High-visibility banner with nested action text and button.
6. **Footer:** Dark bottom bar with centered copyright notice.
